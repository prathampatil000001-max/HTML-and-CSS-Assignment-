📚 CSS Clip-Path Guide

1. Circle()

Creates a circular clipping area.

clip-path: circle(50%);

2. Ellipse()

Creates an oval clipping area.

clip-path: ellipse(50% 35%);

3. Polygon()

Creates custom shapes using coordinates.

clip-path: polygon(50% 0%, 100% 100%, 0% 100%);

4. Shape Outside

Allows text to wrap around floated elements.

float: left;
clip-path: circle(40%);
shape-outside: circle(45%);
